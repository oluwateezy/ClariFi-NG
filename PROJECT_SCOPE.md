# ClariFi NG – Project Scope

## Project Overview

ClariFi NG is a financial management and analytics platform designed to support the organisation, processing and interpretation of financial information.

## Core Product Areas

### Financial Data Management

* Manual financial data entry.
* CSV financial data import.
* Financial data validation.

### Financial Analytics

* Financial calculations.
* Financial summaries.
* Analytical reporting and visual insights.

### User Experience

* User-friendly dashboard.
* Structured navigation.
* Accessible presentation of financial information.

## Quality Assurance

The project will incorporate functional testing, data validation and user acceptance testing to verify that the product meets its approved requirements.

## Project Workstreams

* Project Management
* UI/UX Design
* Software Development
* Data Analytics
* Quality Assurance

## Scope Note

The implementation details and final feature scope will be governed by the approved Product Requirements Document.
